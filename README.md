## 📖 درباره پروژه

این وب‌سایت یک **پلتفرم جامع** برای معرفی من، مهارت‌ها، پروژه‌ها و خدماتم است. هدف اصلی، ساخت یک ویترین حرفه‌ای و مدرن برای جذب کارفرمایان در حوزه‌های **توسعه وب، نرم‌افزار، طراحی گرافیک و کمپین‌نویسی فروش** است.

پروژه از یک صفحه اصلی (Single Page) به یک **وب‌سایت چندصفحه‌ای (Multi-page)** با صفحات تخصصی برای هر خدمت ارتقا یافته است.

🔗 **آدرس سایت:** [https://aydinbeyrampor.ir](https://aydinbeyrampor.ir)

---

## ✨ ویژگی‌های کلیدی

- **صفحه اصلی (Single Page):** شامل بخش‌های Hero، About، Skills، Learning Journey، Projects، Services و Contact.
- **صفحه ویترین (Solutions):** کاتالوگ محصولات و خدمات با فیلتر، جستجو و مودال.
- **صفحات تخصصی خدمات:** ۶ صفحه اختصاصی برای طراحی سایت، نرم‌افزار، اتوماسیون، ربات تلگرام، طراحی گرافیک و کمپین‌نویسی.
- **صفحه پکیج جامع (Full Package):** صفحه فروش ویژه برای راه‌اندازی کامل کسب‌وکار.
- **مودال کمپین اینستاگرام:** شبیه‌ساز پست‌های اینستاگرام برای نمایش نمونه‌کار کمپین‌نویسی.
- **کاملاً واکنش‌گرا (Responsive):** سازگار با موبایل، تبلت و دسکتاپ.
- **منوی چسبان هوشمند (Sticky Navbar):** تغییر ظاهر منو با اسکرول.
- **اسکرول نرم (Smooth Scroll):** پیمایش نرم بین بخش‌ها.
- **انیمیشن ورود (Fade-in on Scroll):** نمایش تدریجی بخش‌ها با اسکرول.
- **دکمه بازگشت به بالا (Back to Top):** ظاهر شدن دکمه بعد از اسکرول.
- **فرم تماس هوشمند:** متصل به سرویس Formspree برای دریافت پیام در ایمیل.
- **دکمه‌های واتساپ و تلگرام:** برای ارتباط مستقیم.
- **افکت‌های درخشان (Neon/Glow):** استفاده از افکت‌های نوری در صفحه پکیج جامع.

🎯 قابلیت‌های فنی پیاده‌سازی‌شده
منوی موبایل: با کلیک روی آیکون همبرگری، منو باز و بسته می‌شود.

ناوبری چسبان: با اسکرول بیش از ۵۰ پیکسل، کلاس scrolled به منو اضافه می‌شود.

اسکرول نرم: با scrollIntoView و behavior: 'smooth' پیاده‌سازی شده است.

انیمیشن ورود: با IntersectionObserver برای عملکرد بهینه.

لینک فعال: با IntersectionObserver بخش فعال در منو مشخص می‌شود.

دکمه بازگشت به بالا: با اسکرول بیش از ۳۰۰ پیکسل ظاهر می‌شود.

فیلتر و جستجوی ویترین: با JavaScript خالص پیاده‌سازی شده است.

مودال‌های پروژه: با اسلایدر تصاویر و اطلاعات کامل.

مودال کمپین اینستاگرام: شبیه‌ساز قاب موبایل با پست‌های اینستاگرام.

فرم تماس: متصل به Formspree برای دریافت پیام در ایمیل.

دکمه‌های واتساپ و تلگرام: برای ارتباط مستقیم با کارفرما.

ذرات ستاره‌ای و افکت‌های نوری: در صفحه پکیج جامع.

🚀 بهینه‌سازی‌های انجام‌شده
بهینه‌سازی تصاویر: تبدیل تمام تصاویر به فرمت WebP برای کاهش حجم.

Lazy Loading: استفاده از loading="lazy" برای تصاویر پایین صفحه.

Defer کردن JS: استفاده از defer برای بارگذاری غیرمسدودکننده جاوااسکریپت.

Tailwind محلی: Build کردن Tailwind CSS به جای استفاده از CDN.

فونت‌های محلی: ذخیره فونت‌های وزیرمتن و Font Awesome در پروژه.

سئو: اضافه کردن متا تگ‌ها، Open Graph، sitemap.xml و robots.txt.

ثبت در Google Search Console: برای ایندکس سریع‌تر صفحات.
